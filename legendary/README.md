# 🌾 Nimireaux Uganda Limited — "Legendary" Edition ("Grain: Revolutionized")

Cinematic dark luxury web edition for **Nimireaux Uganda Limited**, inspired by the award-winning Pioneer *"Corn: Revolutionized"* UI by Zeeuws Web.

> **Tagline:** *"PURE NUTRITION. POWERING POSSIBILITIES."*  
> **Core Services:** *Grain Processing and other Milling Services*

---

## ⚡ Key Architectural Features

1. **Cinematic Chiaroscuro Visual Style**:
   - Deep obsidian & dark forest green background (`#040806`, `#07100b`).
   - Bioluminescent electric lime (`#22c55e`, `#4ade80`) glowing particle constellation canvas and sensor beacons.
   - Warm harvest gold (`#d4a34b`) metallic accents.
   - Heavy condensed display typography (`Bebas Neue`, `Syne`, `JetBrains Mono`).

2. **The 7 Cinematic Chapters**:
   - **Chapter 01 — GRAIN: REVOLUTIONIZED**: Hero stage with chiaroscuro 3D corn visual, glitch-glow text effect, and operational telemetry.
   - **Chapter 02 — FIRST, A SOLID FOUNDATION**: Interactive biological radar of Ugandan grain origins, 3D constellation nodes, and the magnetic circular button (`EXPLORE SOURCING`).
   - **Chapter 03 — OUR MILLING... DIAL IT IN FURTHER**: 4-stage roller milling dial with live sensor telemetry (RPM, roll gap calibration, bearing temperatures).
   - **Chapter 04 — TESTING, TESTING AND MORE TESTING**: Interactive matrix inspection grid (matching video frame 06) with real-time aflatoxin (0.0 ppb) and moisture assay query.
   - **Chapter 05 — SUPERFINE NUTRITION & PRODUCTS**: Flagship flour and cereal products with dynamic nutritional fact label generator.
   - **Chapter 06 — INDUSTRIAL BATCH YIELD ESTIMATOR**: Real-time batch extraction calculator with neon slider (5 to 1,000 MT), bags count, bran by-products, and direct RFQ transfer.
   - **Chapter 07 — COMMERCIAL DESK & THE NIMIREAUX CARD**: Stacked kinetic links with 3D reflection effect (matching video frame 08), the dark luxury edition of the official business card, and live RFQ desk.

3. **Signature Interactive Controls**:
   - **Right-Side Circular Progress Dial**: SVG rotating progress ring with live chapter name badge and steppers.
   - **Minimalist Top HUD**: Left hamburger button triggering full-screen navigation overlay, center matrix status, and Web Audio API synthesizer.
   - **Debounced Wheel & Keyboard Snap**: Seamlessly glide between chapters with keyboard arrows, wheel scroll, or touch swipe.
